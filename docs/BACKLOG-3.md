# バックログ #3（実データ v1.3 の提案品質レビュー → PdM 判断）

出典: 批判役のレビュー（2026-10-05）。シミュレーションの出力は docs/reviews/2026-10-05-tokyo-sim.txt
シミュレーション条件: 新宿 / 吉祥寺 / 錦糸町 / 二子玉川 / 八王子 × 30・60・90分、16km/h

方針: **「おすすめ3件が、毎回行きたくなる・写真付き・正しい名前」** を最優先にする。🔴🟡 は全部、🟢 も全部対応する。

## P0（データ生成）
- Q1 汎用名の置換
  - 対象は次のいずれかに当てはまるもの。
    - 付属建物名
    - 汎用名リスト（八幡神社 / 稲荷神社 / 天祖神社 / 氷川神社 / 展望台 / 城山 / 五重塔 / 三重塔 / 観音堂 / 地蔵堂 など）
    - Wikidata ラベルが元の名前を含み、かつ長い場合
  - 該当したら Wikidata の日本語ラベルに置き換える（例: 本殿 → 明治神宮）。
  - ラベルが無い汎用名は「八幡神社（江東区）」のように市区町村名で補う。
  - 付属建物名で置き換えられなかったものは、wikidata があっても除外する。
  - 英語だけの名前も、QID があれば日本語ラベルにする。
- Q2 動物園・テーマパークの中身
  - attraction=animal を除外する。
  - zoo / theme_park / 大きな公園の範囲内にある node で、wikidata が無い attraction / waterside / historic は親に吸収する。
  - tourism=zoo を取得対象に追加する（カテゴリは attraction）。
- Q3 目的地にならないものを除外する
  - NOT_DESTINATION_RE: スタンプ|調整池|沈砂|御用地|御所$|運動場|グラウンド|ゴルフ|カート|ビーチコート|駐車場|霊園の区画 等
  - QID の除外リスト: 第六台場 Q49173570、赤坂御用地 Q11635414 ほか、立入不可の場所。
  - これらはアプリ実行時の判定（isWorthVisiting）にも共通で入れる。
- Q4 Wikidata の補完
  - OSM の wikidata タグにある全 QID について、`VALUES` で label / P18 / sitelinks / P1435 を別途取得する（クラスでは絞らない）。
  - SPARQL が P31 のみのモードにフォールバックしたら、warnings と stats に記録する。
  - natural=peak（名前あり）を追加する。高尾山などが対象。
- Q6 重複統合
  - 60m 以内で similarName ならカテゴリが違っても統合する。
  - 親子関係（公園内の池、神社の資料館 等）は Q2 の吸収処理を公園の範囲にも広げて対応する。
- Q9 英語名
  - QID が無く、スコア0で、日本語を含まず、飲食以外のものは除外する。
- Q11 小さな史跡
  - wikidata も heritage も無く、名前が 碑|塔|像|墓|台座跡 で終わる史跡・見どころの node は除外する。
- Q12 Wikidata にしか無い橋は sitelinks 4 以上、または heritage ありに限る。
- Q13 チェーン名を追加する（McCafe / ブルーシール / キャラバンコーヒー / ドンレミー / HARBS / 銀座和蘭豆 / 猿田彦珈琲 など）。
- Q14 カテゴリ判定
  - shop / amenity を tourism=attraction より優先する。
  - 商店街（合羽橋道具街 等）は見どころにする。
- Q15 写真
  - wikimedia_commons の Category: リンクは、代表画像を取る（取れなければ近傍検索に回す）。
  - DEFAULT_NEARBY_LIMIT を 1000 にする。
- Q5 カフェなどの加点
  - opening_hours / website / cuisine を保持する。
  - website +1、opening_hours +0.5 で加点する。

## P0（アプリの選定ロジック）
- Q7 おすすめ3件
  - まず「写真あり、またはスコア5以上」の候補から選ぶ。足りなければ全体から補う。
  - 見栄えの加点は min(1.2, score*0.1)。
- Q8 カテゴリ均等割
  - カフェ / パン / 甘味以外は、スコア0を除いてから割り当てる。
  - 同点のときの順序は hash(id+日付) で日替わりにする。
- Q10 候補が少ないとき
  - 質の悪いものを除いた結果が40件未満なら、内径を 0.7 → 0.6 → 0.5 と段階的に広げる。
  - 都境の近く（検索円の30%以上が都外）では、UI に「都外は一部のみ」と表示する。

## 受け入れ基準（同じシミュレーションで計測する）
- おすすめ3件の写真付き率: 74% → **90%以上**
- おすすめにスコア0が出る率: **0%**
- 汎用名・付属建物名・動物名・立入不可の場所がおすすめにも候補にも出ない
- 50m 以内の別名重複: 37組 → **5組以下**
