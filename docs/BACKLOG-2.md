# バックログ #2（v1 レビュー：デザイナー + 批判役 → PdM 判断）

方針: 🔴 は全部、🟡 も原則全部、🟢 は軽いものを採用。「数字の信頼性」と「実データで確実に動くこと」を最優先する。

## P0（実データで動くこと / 正しさ）
- C1 Overpass を軽量化する
  - `[bbox:s,w,n,e]` のグローバル指定に切り替え、円形の絞り込みはクライアント側で行う。
  - 半径は**現在の速度プリセット**×90分から決める。速度を変えたら再取得し、キャッシュキーに速度を含める。
  - historic は値のホワイトリスト方式にする（castle / ruins / monument / archaeological_site / memorial は除外 等）。
  - `[timeout:25]`、1本目のエンドポイントは 15秒、全体の予算は 20秒。
- C2 in-flight 共有の abort バグ
  - 共有 run は専用の AbortController と購読者カウントで管理し、全員が抜けたときだけ abort する。
  - 再現テストを追加する。
- C3 直線フォールバック時は `estimated: route.source !== 'osrm'` とし、一覧への反映は osrm のときだけにする（A8）。
- C4 `useNow()` を導入する
  - visibilitychange / pageshow / focus と 60 秒タイマーで再評価する。
  - 対象: 帰還カード、日没、おすすめの日付シード、期限切れ判定。
- C5 オフライン時の前回結果は、origin が 1km 以内のときだけ使う。保存するのは表示用の上位のみ（容量対策）。
- C6 実API失敗でデモに落ちたとき（`?demo=1` 以外）
  - 再試行ボタンと、visible 復帰時の自動再試行を用意する。
  - カードから直接出発するボタンは無効にする（詳細の注意書き付きボタンのみ）。
- C7 おすすめ3件は「dateKey+時間+出発地+速度」で固定する。標高到着後に並び替えない（水面ペナルティは一覧の並びのみに使う）。
- C8 水面判定: 始点と終点が >0m で、中間が ≤0m のまま 3 点以上連続した場合だけにする（ゼロメートル地帯の誤判定対策）。
- C9 useOrigin
  - 世代番号で古い GPS 結果を捨てる。
  - err.code で文言を分ける（拒否 / タイムアウト / 取得不可）。
  - 精度が 500m を超えたら高精度で再取得する。
- C10 出発地が manual のときは Maps URL に `origin=` を明示する（片道・往復とも）。
- C11 Commons の近傍写真
  - 対象は公園・展望・寺社・史跡のみ。
  - ファイル名に施設名の一部（2文字以上）が含まれる場合を優先する。
  - 近傍写真を採用したときは「付近の写真」と表示する。
- C12 Retry-After に依存しない。`navigator.onLine` なのに TypeError → busy 扱いにし、次のエンドポイントへ移る。
- C14 fetchJson は本文パースが終わるまでタイムアウトと abort を維持する。

## P0（数字の信頼性 / デザイン）
- D1 標高グラフ（詳細・ミニとも）
  - 最小縦レンジは 60m。`span=max(実レンジ×1.15,60)` で中央寄せし、10m 単位で丸める。
  - 軸ラベルは軸の端の値にする。補助線 1 本。
  - 右上に「高低差 Xm」を表示する。
  - 往復の折り返し線は距離から計算した位置に引く。
- D2 計算と表示の一本化（D2 と C13 をまとめて対応）
  - `tripEstimate(place, mode)` を 1 関数にし、カード・ガチャ・詳細・出発記録で共有する。
  - 経路距離が取れたら Map に保存し、一覧の距離と時間にも反映する。
  - 走行時間は 5 分単位で丸める（15 分未満のみ 1 分単位）。
  - 値が更新されたら、カウントアップと「経路で更新」ピルを 2 秒表示する。
  - カードは「片道5.4km」と明記する。
  - 詳細の標高は「+22m / 往復の上り」とし、その下に「片道 +11m · フラット」を添える。
- D3 ガチャ
  - スクリムに backdrop-filter: blur(10px)。
  - 「やめとく」はテキストリンクにし、ボタン群は下寄せにする。
  - 主ボタンを「🚲 ここに決めて出発 →」にして Maps へ直行し、下に「くわしく見る」リンクを置く（デモ落ち時は C6 に従う）。
  - 未訪問なら NEW リボン。演出中に「N件の中から…」を表示する。
- D4 FAB
  - おすすめのみ表示中は出さない。
  - 一覧では下スクロールで隠し、上スクロールで表示する。
  - 最後のカードの下に padding-bottom 88px。
- D5 設定アイコンを歯車にする。
- D6 詳細シートの並び
  - 片道 / 往復のセグメントを店名の下・スタッツの上に置く（高さ 40px）。
  - ラベル（のんびり平坦等）は標高見出しの横。
  - 注記は短くし、重複を削る。
- D7 フォールバック画像
  - 絵文字を上寄せにし、名称と重ならないようにする。
  - おすすめカードの暗いオーバーレイを削除する（上部のみ薄く）。
  - ダークモードでは photo filter を確認し、ピルを半透明にする。

## P1（UX 改善）
- D8 ホーム
  - 到達レンジは 240px、scale 0.55〜1.0。絵文字は逆スケールで 22px を保つ。
  - 実際の候補カテゴリから最大 6 個をポップインで出す。
  - 「この範囲に N か所」（デモ時は明記）。ダイヤルは CTA の直上に寄せる。
- D9 おすすめカード
  - 「⏱ 40分 · 片道5.4km」を大きな数字で表示する。
  - 右にミニ標高グラフを置き、「くわしく」は写真またはタイトルのタップで開く。
  - デモの注記は件数行に 1 か所だけ。
- D10 帰還カードを 1 行の帯（64px）に縮める。
- D11 高低差バッジは淡い背景色＋濃い文字色に統一する。「推定」は `≈` に置き換え、DESIGN を改訂する。
- D13 フィルタ
  - 1 段の横スクロールに統合する。
  - カテゴリは選択中だけラベルを出す。
  - 件数と並び順は 1 行にまとめる。
- D14 「走った！」は全幅、「昨日の分として記録」はテキストリンクにする。
- D15 出発地が未確定のときは CTA を「出発地をえらぶ →」にする。金枠の二重表示を解消する。
- D16 数字前後の余分な margin と、件数表記のゆれを直す。
- C16 SW の更新は prompt 型にする（「新しいバージョンがあります」トースト）。ホーム表示中だけ即時適用。
- C17 engines は `>=22.12`。README も合わせて修正する。
- C18 IntersectionObserver の unobserve 漏れ。PlacePhoto の状態リセットは key で行う。
- C19 iOS の背景スクロールロックは position:fixed 方式。id は useId で付ける。
- C20 Nominatim は Promise チェーンで直列化する。
- C21 places 変更時の enrichment を 300ms debounce する。
- C22 popstate で詳細とシートを閉じる（開くときに pushState）。
