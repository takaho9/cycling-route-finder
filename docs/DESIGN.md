# DESIGN: Cycling Route Finder デザイン仕様書 v1

作成: UIデザイン / 2026-10-04 / 対象: PRD v1
実装前提: Vite + React + TypeScript + 素のCSS（CSS Modules または単一CSS）。外部UIライブラリなし。アイコンはインラインSVG＋絵文字。

---

## 0. デザイン原則（迷ったらここに戻る）

1. **10秒で外に出る** — 画面の主役は常に「次に押すべき1つ」。CTAは親指ゾーン（画面下 1/3）に置く。
2. **行き先は"旅先"として見せる** — 写真を大きく、距離や数字は旅のチケットのようにリズムよく。業務アプリ的な表・罫線は使わない。
3. **数字はヒーロー** — 「45分」「8.2km」「+120m」はディスプレイフォントで大きく。
4. **褒める、急かさない** — 習慣化UIはポジティブな言葉だけ。ストリークが切れても責めない。
5. **待ち時間も楽しい** — スケルトン→写真フェードイン→標高グラフが描かれる、の段階表示。

### 2.4 モーション

| 変数 | 値 | 用途 |
|---|---|---|
| `--dur-fast` | `120ms` | 押下・トグル |
| `--dur-base` | `220ms` | チップ切替・フェード |
| `--dur-slow` | `360ms` | シート開閉・カード出現 |
| `--dur-epic` | `1600ms` | ガチャ演出全体 |
| `--ease-out` | `cubic-bezier(.2,.8,.2,1)` | 標準（出現） |
| `--ease-in` | `cubic-bezier(.4,0,1,1)` | 退場 |
| `--ease-spring` | `cubic-bezier(.34,1.56,.64,1)` | 選択時の「ポンッ」、スタンプ押印 |

ルール:
- 押下: `transform: scale(.97)`（`--dur-fast`）。
- カード一覧の出現: 上から 40ms ずつ遅延、`opacity 0→1` + `translateY(12px→0)`、最大8枚まで遅延（以降は同時）。
- 写真ロード完了: `opacity 0→1`（`--dur-base`）。標高グラフ: `stroke-dashoffset` で左→右に描画（`--dur-slow`）。
- **`prefers-reduced-motion: reduce`**: 全 `transition/animation` を `opacity` のみ・`--dur-fast` に置換。ガチャはリール回転を省略し、即座に結果カードをフェード表示。スケルトンのシマーは停止（静的な `--c-surface-2` 塗り）。振動（`navigator.vibrate`）も行わない。

## 3. 画面構成とワイヤー

画面は SPA の3レイヤー: **ホーム（時間選択）→ 候補一覧 → 詳細ボトムシート**。ガチャ・記録はモーダル/シート。下部タブバーは持たない（迷わせない）。ヘッダー右に「記録（🔥ストリーク）」と「設定（⚙）」のみ。

### 3.1 ホーム — 「タイムダイヤル」

コンセプト: 画面下半分に**半円のダイヤル**。親指で弧をなぞると時間が変わり、中央に「行ける範囲」が波紋のように広がる。選択＝ワクワクの予告。

```
┌──────────────────────────────┐
│ ちょいチャリ        🔥3  ⚙   │ ← ヘッダー 56px
│                              │
│  📍 千代田区丸の内 付近  変更 › │ ← 現在地ピル（タップで手動変更）
│                              │
│   今日は どこまで行く？        │ ← h1
│                              │
│        ·  ·  ◯  ·  ·         │ ← 到達レンジの同心円イラスト
│      ·   ( 🚲 )    ·         │   （選択時間に応じて円が拡縮）
│        ·  ·  ◯  ·  ·         │
│      片道 およそ 6.4km 先まで   │ ← --fs-sub、数字のみ --font-num
│                              │
│         ╭─ 45 ─╮             │
│      30 ╱  分   ╲ 1h          │ ← 半円ダイヤル（下端が画面下）
│    15 ●         ○ 1h15        │   ● 6つの目盛り＝時間チップ
│      ╲  ━━━━━━━━  ╱ 1h30      │   ノブをドラッグ or 目盛りタップ
│                              │
│ [ 🎲 おまかせ ] [ 候補を見る → ] │ ← 下部固定。主CTAは右・幅広
└──────────────────────────────┘
```

仕様:
- ダイヤル: 幅 `min(100vw - 32px, 360px)`、半円の弧を 6 等分（左15分→右1時間30分、約30°間隔）。弧の太さ 20px、非選択部 `--c-surface-2`、選択地点まで `--g-hero` で塗る（プログレス表現）。ノブ 44px 円・白・`--sh-2`。
- 中央表示: 「45」(`--fs-hero`) ＋ 単位「分」/ 60以上は「1:15」表記＋「時間」。値変化時は数字が縦スクロールで切替（`--dur-base`、reduce時はフェード）。
- 目盛り間はスナップ（中間で止まらない）。スナップ時に `navigator.vibrate(8)`（対応端末のみ）。
- 実装: SVG（`<path>` の弧 + `<circle>` ノブ）、Pointer Events で角度→インデックス変換。**アクセシビリティ**: `role="slider"`、`aria-valuemin=0 max=5`、`aria-valuetext="45分、片道約6.4km"`、←→キーで1段移動。ダイヤルの下に視覚的に隠した通常ラジオ群は不要（slider で十分）。
- 到達レンジイラスト: 3重の同心円（`--c-accent` 15%/10%/5% 不透明度）。選択時間に比例して最外円のスケールを `0.4〜1.0` にアニメ。円上に小さなカテゴリ絵文字（☕⛩🌳）が散らばり「この範囲に何かある」を予告。
- 速度プリセットは現在値をダイヤル下に小さく「ふつう 16km/h ›」と表示（タップで設定シート）。
- 初期値: 前回選択（localStorage）、初回は 45分。
- 「候補を見る」押下で一覧へ遷移（取得はダイヤル確定時点で先行開始し、体感を短縮）。

カード仕様:
- 写真 `aspect-ratio: 16/10`、`object-fit: cover`、未取得時はフォールバック（§5）を表示し、写真が来たらクロスフェード。
- 写真上: 左上カテゴリピル（`rgba(255,255,255,.9)` 背景・黒文字・`--fs-caption`）、右上 ♡（44px タップ領域）。下部に名称（2行まで省略）とメタ「片道5.8km · 往復42分」。数字は `--font-num`。
- 写真下の帯（高さ 48px、`--c-surface`）: 左に高低差バッジ（§4）、右にミニ標高グラフ（幅 96px × 28px、SVG polyline、線色＝ラベル色、下を同色 15% で塗り）。標高未取得中は帯の右側をシマー。
- 訪問済み: メタ行末に `✓ 行った` ピル（`--c-accent`）。
- 1列レイアウト（スマホ）。幅 ≥ 720px で2列、≥ 1080px で3列（`grid-template-columns: repeat(auto-fill, minmax(320px,1fr))`）。

フィルタ/並び替え:
- ヘッダー下 sticky（`top: 56px`、背景 `--c-bg` 92% + `backdrop-filter: blur(12px)`）。
- 高低差チップ: 単一選択（全部/平坦/ゆる/ヒル）。選択時に各色の塗り＋白文字。
- カテゴリ: 複数選択の絵文字丸チップ（40px円、ラベルは `aria-label`）。選択時 `--c-primary` リング 2px。
- 並び替え: ネイティブ `<select>` を見た目だけ整える（近い順 / 遠い順 / 平坦順 / ランダム / 行ったことない順）。
- 件数行: 「32件の行き先」＋デモ時は「· デモデータ」ピル（§3.6）。
- フィルタで0件になった時は §3.6 の空状態を一覧内に表示。

- スタッツ: 数字 `--fs-display`、ラベル `--fs-caption --c-text-sub`。高低差セルは数字の色をラベル色に。
- 標高プロファイル: SVG。面グラデ（ラベル色 35%→0%）＋線 2px。Y軸は最小/最大値のみ表示、X軸は出発/到着アイコン。往復モード時は折り返し点に縦破線＋「📍」、横幅を往復分に拡張。タップ/ドラッグで縦カーソルと「1.8km地点 · 42m」ツールチップ。経路が直線補間の場合、図の右下に「※ 直線で推定」(`--fs-caption`)。
- 片道/往復セグメント: 高さ 44px、選択側 `--c-accent` 塗り白文字。切替で距離/時間/獲得標高の数値をカウントアップ（`--dur-base`）。初期は「往復」（運動目的のため）。
- 主CTA「Googleマップで出発」: `--c-primary`、白文字 18px/700、右端に → が押下で 4px 右へ。新規タブ（PWAでは外部アプリ）で開く。
- 「走った！」: 押すと §3.5 の記録演出。記録済みの日は「✓ 今日走った！」に変化し無効化ではなくトグル（取り消し可）。
- フォーカス管理: 開いたらシート見出しへフォーカス、`Esc`/✕ で閉じて元カードへ戻す。`role="dialog" aria-modal="true"`。

### 3.4 ガチャ演出（迷ったらランダム）

入口: ホームの「🎲 おまかせ」ボタン、一覧ヘッダーの🎲、一覧右下FAB。対象は現在のフィルタ適用後の候補。

演出（計 `--dur-epic` 1.6s）:
1. 画面全体に `--c-scrim`、中央にカプセル（直径 120px の円、上半分 `--g-hero`、下半分白）がポップイン（`--ease-spring`、0〜250ms）。
2. カプセルが左右に 3回揺れる（250〜900ms、`rotate(±12deg)`）。下部に「どこにしよう…」。
3. パカッと割れて（上下に分離、900〜1150ms）、中から光の放射線（`--c-gold` の放射状 conic-gradient、回転）。
4. 結果カード（一覧カードと同デザイン、幅 90%）が下からせり上がる（1150〜1600ms）。紙吹雪は CSS のみ（12個の小矩形、ゴールド/オレンジ/ティール、落下 800ms）。

結果カード下のボタン:
- 主: 「ここに決めた！」→ 詳細シートを開く
- 副: 「もう1回 🎲」（直前の結果は除外して再抽選）
- テキストリンク: 「やめとく」

reduce-motion: ステップ1〜3を省略し、結果カードをフェード表示（`--dur-fast`）。候補0件時はガチャボタンを無効化せず、押下時に「今の条件だと候補がないみたい。フィルタをゆるめてみよう」トースト。

### 3.5 習慣化（ストリーク・今週の回数・スタンプ）

**ヘッダーの🔥バッジ**: 連続日数を常時表示（0日なら🔥をグレーで「0」ではなく「🚲」アイコンのみ）。タップで「きろく」シート。

## 4. 高低差の可視化ルール

指標: **獲得標高 G（m、片道経路の累積上り）** と **上り比率 R = G ÷ 片道距離(km)（m/km）**。短距離で G が小さくても急坂なら「ヒル」になるよう、両方で判定する。

| ラベル | 条件（上から順に判定） | 色 | アイコン |
|---|---|---|---|
| 🔴 **ヒルクライム** | R ≥ 15 m/km **または** G ≥ 150m **または** 最大勾配 ≥ 8% | `--c-hill` | 山2つの尖ったSVG（▲▲）＋絵文字🔴 |
| 🟡 **ゆるアップダウン** | R ≥ 6 m/km **または** G ≥ 40m | `--c-rolling` | 波線SVG（〰）＋🟡 |
| 🟢 **フラット** | 上記以外 | `--c-flat` | 水平線SVG（━）＋🟢 |

- 最大勾配は 100m 以上の区間で平滑化した値を使う（標高サンプルのノイズで誤判定しないため）。
- バッジ表記: `[アイコン] +86m ゆる`（高さ 28px、`--r-sm`、ラベル色塗り）。色だけに頼らず**テキストとアイコン形状**で区別（色覚多様性対応）。
- 往復表示時の G は往路上り＋復路上り（＝往路の下り）の合計。ラベル判定は常に片道基準で固定（切替でラベルが変わると混乱するため）。
- 一覧の文言: フラット「のんびり平坦」/ ゆる「ほどよくアップダウン」/ ヒル「登りごたえあり」（詳細シートのサブテキスト）。

## 5. 写真フォールバックビジュアル

構成: カテゴリ別 **斜めグラデーション（135deg）** ＋ 中央に大きな絵文字（写真枠高さの 40%）＋ 右下に半透明の大きな同絵文字（200%、opacity .12、`rotate(-12deg)`）で奥行き。さらに下部に白 10% の緩い波線SVG（道のモチーフ）を共通で重ねる。同カテゴリ内で単調にならないよう、場所IDのハッシュで **グラデ角度を 115〜155deg** で揺らす。

## 7. PWA アイコン / テーマカラー / スプラッシュ

**アイコン（SVG、512×512 基準）**
- 背景: 角丸なしの全面 `--g-hero`（`#FF5A1F → #FFB800`, 135deg）。maskable 対応のため主要モチーフは中央 80%（セーフゾーン半径 205px）内に収める。
- モチーフ: **白い円形の時計の文字盤（中心 256,256、半径 150、線幅 28）** の中に、**自転車の車輪のスポーク**を兼ねた2本の針（12時方向と、45分を示す 9時方向、線幅 28、端は round）。文字盤の右下 4時位置から外へ **ティール `#0E8C8C` の小さな位置ピン**（高さ 110）が飛び出す。＝「時間 × 自転車 × 行き先」。
- 要素はすべて `circle` / `line` / `path` 3〜4個で構成可能。16px ファビコンではピンを省き、文字盤と針のみ。
- 出力: `icon-192.png` / `icon-512.png` / `maskable-512.png`（背景を全面に塗ったもの）/ `apple-touch-icon-180.png` / `favicon.svg`。

**manifest**
- `name`: 「ちょいチャリ — 時間でえらぶサイクリング」、`short_name`: 「ちょいチャリ」
- `theme_color`: `#FF5A1F`、`background_color`: `#FBF8F3`
- `display`: `standalone`、`orientation`: `portrait`
- HTML の `<meta name="theme-color">`: Light `#FBF8F3`（ヘッダーと地続きに見せる）、Dark `#0F1419` を `media` 属性付きで2つ。

**スプラッシュ**
- Android: manifest の `background_color` ＋ アイコンで自動生成（追加作業なし）。
- iOS: 個別画像は作らず、アプリ起動直後の HTML 初期表示（`index.html` 内のインラインCSS）で同等の見た目を出す: 背景 `--c-bg`、中央にアイコン（96px）、その下にロゴタイプ「ちょいチャリ」（Noto Sans JP 700, 22px）、最下部にタグライン「時間をえらんで、どこかへ。」（`--c-text-sub`）。React マウント後 `--dur-base` でフェードアウト。reduce-motion 時は即時切替。

## 8. 実装メモ（デザイン観点のチェックリスト）
